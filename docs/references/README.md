# Nguồn tham khảo

Đây là đầu mối tra cứu các nguồn bên ngoài đã dùng trong tài liệu Curve E.
Mốc khảo sát hiện có: 28/10/2026; các URL động có thể thay đổi sau mốc này.

| Nhóm nguồn | Nội dung |
| --- | --- |
| [ZMK và Studio](official.md#zmk) | Tài liệu board/module, layout, encoder, chuột, BLE, nguồn và công cụ Studio |
| [EBYTE E73](official.md#ebyte-e73) | Trang sản phẩm, manual module ứng viên, checksum PDF và giới hạn nhận diện |
| [Bootloader, Nordic và OpenOCD](official.md#bootloader-nordic-và-openocd) | Source nền theo commit, sơ đồ bộ nhớ, ACL/APPROTECT, hành vi recover và giấy phép |
| [Khảo sát nguồn vendor](public-sources.md) | Repo đã tìm, kết quả CAD/BOM, firmware Curve, nhánh/commit và dependency |
| [Snapshot nguồn lưu trong repo](../../archive/upstream/README.md) | Archive, LICENSE, phạm vi bản sao và cách đối chiếu checksum |
| [Manifest snapshot](../../archive/upstream/sources.json) | URL gốc, commit và hash có thể đọc bằng máy |

Kết quả áp dụng cho bo nằm trong [phần cứng](../hardware.md),
[firmware](../firmware.md) và [audit khôi phục](../recovery.md).
URL trong JSON provenance được giữ nguyên để truy xuất nguồn chính xác.
